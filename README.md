Cloud Security — Unit 3 Assignment

Set Up a Web Application on Amazon EC2

Project Overview

This project demonstrates how to host a simple HTML web application on an Amazon EC2 Linux instance using the Apache HTTP Server.

Technologies Used

Amazon Web Services (AWS EC2)

Amazon Linux 2023

Apache HTTP Server

HTML

SSH

AWS Security Groups

Implementation Steps

Launch an Amazon Linux EC2 instance.

Configure SSH (port 22) to allow access from your IP address.

Allow HTTP traffic on port 80 for website access.

Connect to the instance using SSH.

Install and start Apache.

Deploy the HTML webpage.

Verify the website using a browser and curl.

Security

Restrict SSH access to your IP address.

Keep private keys and passwords confidential.

Allow only the network traffic required for the practical.

Project Files

index.html — Web application source code.

Unit_3_Cloud_Security_Assignment.pdf — Practical report and documentation.

Conclusion

This project demonstrates basic web hosting on AWS EC2 and the importance of secure remote access and network configuration.
